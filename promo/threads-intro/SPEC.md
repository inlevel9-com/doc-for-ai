# SPEC — AI 문서 변환기 스레드 소개 영상

캔버스 1080×1350, 30 fps, 20.0 s, 무음. 배경 #0b1220(남색), 잉크 #ffffff, 강조 #c4f87a(아이콘 연두), 보조 #94a3b8. 서체 Pretendard(자막 ExtraBold, UI Regular/Bold).

## 자막 규칙
- 위치: 세로 1040–1200 px 띠(타이틀 세이프 안), 가운데 정렬, 최대 2줄, 글자 60 px ExtraBold, 줄 간격 1.25.
- 등장: 단어별 blur 6→0 + 불투명 0→1, 0.13 s, 단어 간 0.07 s. 퇴장: 0.18 s blur-out. 한 줄당 최소 홀드 0.5 s + 0.3 s/단어.
- 강조 단어 하나만 연두(#c4f87a).

## 창 규칙
- 앱 창 940×≈760 px, 좌우 70 px 여백, 상단 150 px부터. 모서리 14 px, 그림자 0 30px 80px rgba(0,0,0,.55).
- Windows 11 타이틀 바: 높이 48, 아이콘 24 + 제목 15 px, 우측 ─ ☐ ✕.
- 커서: 70 px 흰 화살표(검정 테두리). 오른쪽 아래에서 진입, 0.5 s `power3.inOut`, 클릭 시 버튼이 0.95로 눌렸다 복귀(0.12 s).
- 이동 0.3–0.6 s, 도착은 `expo.out`, 퇴장은 `power3.in`, 퇴장은 등장보다 40 % 짧게. 같은 등장 방식 반복 금지(장면마다 다르게).
