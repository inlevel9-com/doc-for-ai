AI 문서 변환기 - 사용법

1. ZIP 압축을 모두 푼 뒤 docforai.exe를 엽니다.
2. 변환할 문서나 폴더를 위쪽 상자에 끌어다 놓거나 파일 선택 버튼으로 엽니다.
3. [③ 변환 시작]을 누릅니다.
4. 기본 설정에서는 원본 옆 변환결과 폴더에 .md와 .json이 저장됩니다.

변환할 수 있는 문서: 한글(HWP/HWPX), 워드, 파워포인트, 엑셀, PDF, 텍스트/Markdown, CSV, JSON, XML, HTML, EPUB,
ZIP(안의 문서를 모두 변환), 그림과 소리 파일(촬영 정보·태그 같은 메타데이터만).

JSON을 엑셀로 되돌리기: [JSON → 엑셀로 되돌리기…] 버튼을 누르고 변환결과 폴더의 .json을 고르면
같은 이름의 .xlsx가 만들어집니다. 명령줄에서는 docforai to-excel 파일.json 입니다.

실패한 문서는 빨간색으로 표시됩니다. 항목을 두 번 누르면 이유를 볼 수 있습니다.
구형 .doc/.ppt를 변환하려면 docs/OFFLINE.md의 LibreOffice 안내를 참고하세요.
